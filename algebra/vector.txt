Chapter 1: Vector
Definition

A vector is a mathematical object that possesses:

Magnitude (size or length)
Direction

Unlike a scalar, which only has magnitude.

Scalar vs Vector
Scalar

Examples:

Temperature = 30°C
Weight = 60 kg
Age = 20 years

These have only magnitude.

Vector

Examples:

Velocity = 50 km/h East
Force = 100 N upward
Wind = 20 km/h North

These have both magnitude and direction.

Terminology You Must Know
Term	Meaning
Scalar	Single value
Vector	Ordered list of values
Dimension	Number of components
Magnitude / Norm	Length of vector
Unit Vector	Magnitude = 1
Feature Vector	Data point represented as a vector
Dot Product	Multiplication measure between vectors
Normalization	Converting vector to unit length
Cosine Similarity	Measures similarity between vectors
Data Science Perspective

When you open a dataset:

Age	Income	Experience
22	50000	1
30	90000	7

The computer does not see a table.

It sees vectors:

[22,50000,1]
[30,90000,7]

Machine Learning is fundamentally about performing mathematical operations on these vectors.
